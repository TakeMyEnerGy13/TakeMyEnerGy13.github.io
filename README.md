# TakeMyEnerGy — portfolio

Минималистичное тёмное портфолио: интерактивная Земля, объёмные логотипы AI-инструментов, проекты, навыки и контакты.

## Запуск

Node.js 18+. Установка пакетов и сборка не нужны.

```sh
npm start
```

Открыть http://127.0.0.1:4173. Порт задаётся переменной окружения `PORT`.

```sh
npm run check
```

## Устройство

- `index.html` — контент и доступная семантическая разметка.
- `style.css` — адаптивная вёрстка, Inter и Instrument Serif.
- `scene.js` — WebGL без библиотек: текстурированная сфера, рельеф, ночные огни, атмосфера; экструзия четырёх SVG-логотипов со скруглёнными краями и боковыми стенками; цветные частицы.
- `app.js` — системная настройка анимации, московское время, копирование email.
- `assets/` — локальные шрифты, SVG и текстуры. Источники перечислены в `assets/SOURCES.md`.
- `server.mjs` — локальный сервер разработки без зависимостей.
- `DESIGN.md` — принятые решения по визуальному стилю.

Контент проектов и контакты взяты из https://takemyenergy13.github.io/. Новое визуальное направление основано на пользовательском DESIGN.md, https://resend.com/ и приложенном референсе композиции Wise. Иллюстрации интерфейсов проектов выполнены в HTML/CSS и не являются скриншотами приложений.

3D учитывает `prefers-reduced-motion`, останавливается за пределами видимой области или при скрытии вкладки. Если WebGL или нужные ассеты недоступны, остаётся статичная композиция с планетой и логотипами. После восстановления WebGL-контекста GPU-ресурсы создаются заново.

Для статического хостинга нужны `index.html`, `style.css`, `app.js`, `scene.js` и `assets/`. Пути поддерживают размещение в подкаталоге. Публичный деплой не выполнен.

Обновлённая версия проверена в Chromium:

- `npm run check` — синтаксис JavaScript корректен.
- Визуальная проверка hero и тёмных проектных иллюстраций; мобильная версия 390 px без горизонтального скролла.
- 3D загружается без ошибок; навигационные якоря существуют; настройка reduced motion управляет анимацией.
- При отключённом WebGL показывается запасная композиция.
- Lighthouse desktop: Accessibility 100, Best Practices 100, SEO 100. Эти оценки не включают производительность 3D и не заменяют проверку на физических мобильных устройствах.
